# Atmospheric propagation

Atmospheric propagation for Cherenkov-telescope simulations: extinction, refraction and timing from the refractive-index profile, optional single scattering, and early photon thinning, as a standard-library-only C++20 core with a Python API, working on photon streams.

Status: alpha; the APIs may change before version 1.0. Extinction (with wavelength assignment and thinning), refraction and timing, optional single scattering ([scattering](scattering.md)) and the atmosphere stage on photon streams ([propagation](propagation.md)) are implemented.
