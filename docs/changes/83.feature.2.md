The Python photon-stream `Reader` and `Writer` accept any path-like object, the `Reader` works as a context manager and has `close()`, and reading no longer copies the photon columns twice or holds the GIL while the native reader works. `Reader("-")` reads stdin through the same buffered stream as the native tools. `obdeect stream cat` with a closed standard output reports a one-line error instead of a Python traceback. The `transform` stage no longer truncates its output before the input is opened, and its `telescope` metadata is no longer changed by the output frame.
