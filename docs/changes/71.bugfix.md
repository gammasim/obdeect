The `cz` column check of photon streams compares `cz` with `-sqrt(1 - cx^2 - cy^2)` in the squared form `cz^2` against `1 - cx^2 - cy^2`. Photons with near-horizontal directions (|cz| below about 1e-3) that a float32 stream stores as a unit vector are no longer rejected by the propagation, sources and ray-tracing stages ("cz column does not match cx, cy"). The check still requires `cz < 0`, and a clearly wrong `cz` is still rejected.
