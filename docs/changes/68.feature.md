Trace an optional flat or spherical camera window (LST PMMA dome): refraction at both
surfaces, Fresnel and bulk losses, and the delay inside the window. A model with window records
needs `obdeect ray-tracing compile --camera-window flat|sphere`: `flat` keeps the flat-window
approximation (`camera_filter`), `sphere` traces the window and requires `camera_filter` to be
`none`.
