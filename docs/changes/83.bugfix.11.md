Sources: a disc target samples only the photons that reach the disc (weight 1 per hit), drawn in the smaller of the profile cone and the cone enclosing the disc (rejection on the disc, and on the profile in the disc cone), so narrow beams and small, distant discs both stay cheap; the expected count integrates the profile over that region (exact on the axis), instead of writing mostly zero-weight rows. The automatic target gives a sphere to every point outside the telescope sphere (not only beyond 1.02 R), and the event metadata key `targets` lists the emissions with a sphere or disc target. Ground-run rows that enter the telescope sphere lie on it to float32 rounding (the direction is normalised before the entry point is solved). Seeds above 2^63 - 1 are rejected, a Gaussian width of 0 is rejected with its key path, and the single-emission API returns the count of photons dropped for the plane.
