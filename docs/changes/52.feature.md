Atmosphere stage: `obdeect propagation run --telescopes ID[,ID...]` (Python: `telescopes=`) keeps only the listed telescopes. Their photons are not decoded; the blocks of other telescopes are dropped from the output. The kept telescopes' output is byte-identical to the full run with the other blocks removed. Not combined with scattering. `obdeect.stream.Reader(path, photon_telescopes)` skips the photons of other telescopes the same way.
