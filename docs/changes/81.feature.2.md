Sources in all directions. A `plane_wave` accepts horizontal directions with the new key `start_distance_m` (the start plane is perpendicular to the beam at that distance; `start_z_m` (default 0) stays for non-horizontal beams; giving both keys is an error). The `lidar`, `laser-beam` and `beam-scan` presets accept horizontal beams: a horizontal beam has no `--max-tilt` limit and starts at `--start-distance` along the beam. A run with frame `ground` writes sphere rows (format 1.2, `ground_representation = "sphere"`): emission points relative to the telescope sphere centre, entry points on the sphere with `path`, and photons that miss the sphere counted as `misses_sphere`.
