Ray tracing: the photon-stream tracer exists once, in C++. `obdeect.ray_tracing.stream.trace_stream` calls the code of `obdeect-ray-tracing-trace-stream`, so the command and the Python function write the same bytes. The Python tracer, its NumPy and CPython emulation, and the unreachable argparse `trace-stream` subcommand are removed. The photons weight sum of each telescope block is taken in output order, so it does not depend on the input chunking, and the input planes of an optical model are computed once per pointing instead of once per event.
