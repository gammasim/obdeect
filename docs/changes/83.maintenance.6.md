Ray tracing: the simulation-models and sim_telarray importers moved to `obdeect.ray_tracing.importers`; the old modules (`compiler`, `repository`, `formats`, `simtel_tables`) re-export them. The model's bounds moved to `obdeect.ray_tracing.bounds`, the optical-model hash has one Python implementation (`hashing`) and one native check (`model_hash.hpp`, covered by the shared fixture in the C++ tests), `OpticalModel` shares one thread pool per thread count, and the obscurer ids of crossings are looked up without a Python loop. JSON paths in error messages are built only when an error is reported.
