Atmosphere stage: optional Earth curvature for the extinction airmass (`curvature` = `none`, `corsika` or `spherical`, with `earth_radius_m`); the slant optical depth replaces the plane-parallel airmass, and CORSIKA CURVED input is detected from the EVTH flag so that curvature is never applied twice. In `spherical` mode the rays are also bent in spherical shells and the air delay follows the bent ray when an atmospheric profile is given (with `refraction_applied` = 1 only the air delay is added). See the propagation curvature page.
