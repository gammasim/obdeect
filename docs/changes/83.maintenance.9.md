Speed up and simplify the stream converters without changing their output (byte-identical golden outputs): sim_telarray output converts each chunk in place, the efficiency checks are cached per telescope and run, CORSIKA containers are read without copies, GrISU lines are formatted with `std::to_chars`, and the C API buffers its file-descriptor output. Duplicate helpers (EVTH flags, number and array lookups, the 1205 header, the tool input and output setup) are shared, and unused API (`TelposCm`, the camera-map overloads of `PsToSimtel` and `stream_to_simtel`, the `parse::` forwarders, `grisu_to_corsika_position`) is removed.
