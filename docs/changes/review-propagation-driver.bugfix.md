Propagation run accounting: scattered photons that miss the telescope are counted (`scattered_dropped`, `scattered_dropped_by_reason`), thinned photons are counted (`thinned_out`, `scattered_thinned_out`), so every photon has one fate in the summary. Photon blocks of a telescope in an event must continue `first_index` (a restart repeated the random keys and is rejected), and with scattering a telescope may have one block per event. The propagator is no longer copyable (its scattering profile pointer would dangle).
