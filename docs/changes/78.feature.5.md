`obdeect propagation to-sky` (and `obdeect.propagation.to_sky`) converts the ground-frame photons of a CORSIKA stream back to the sky frame, the inverse of the atmosphere stage's sky-to-G step, so single scattering can be applied to shower light. `run --scattering` accepts `--scattering-primaries` (scatter only the photons of selected telescopes) and `--telescopes` (keep selected telescopes as scattering targets).
