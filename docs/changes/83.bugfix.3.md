`obdeect::stream::Writer` (and the Python `Writer` and the C API) refuses a record that breaks the record nesting the Reader enforces, for example an event outside a run or `finish()` with a run still open, before writing any of its bytes. Efficiency status records the Reader rejects are refused too. Stream errors are typed (`MalformedStreamError`, `TruncatedStreamError`, `UnsupportedVersionError`, `StreamReadError`), and the C API maps them by type instead of by message.
