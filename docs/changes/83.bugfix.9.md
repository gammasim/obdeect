Ray tracing: `psf.summary` no longer replaces zero weights by uniform ones (no PSF is given, and `detected_weight` reports the weight), rejects a PSF fraction outside (0, 1], and needs the sampled photon count for detected-only results (the effective area was wrong for them). The plot draws frustum obscurers and oriented plates, no longer changes the matplotlib backend on import, and the `plot` command reports bad JSON and bad arrays as errors instead of a traceback.
