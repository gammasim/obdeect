obdeect sources: one run description (TOML or JSON) and one writer replace the seven
LightEmission-style programs. Sources are points, lines, plane waves or sky background with an
`auto` target; `obdeect sources run <file|preset>` and `obdeect sources check` replace the
executables; presets flasher, led, point-source, beam-scan, laser-beam, lidar (new), night-sky,
muon and shower (new). Options are SI, device geometry is required input, and every emission uses
the seed `source_seed(run.seed, k)`. Not backwards compatible: old options, programs and the old
Python source dictionaries are removed, and photon streams differ from earlier versions.
