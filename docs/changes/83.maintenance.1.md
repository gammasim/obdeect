Build system: the CMake helpers shared by the components live in `cmake/` (warnings, core options, stream lookup, Python module, test registration) and each component sdist carries a copy. Native tests carry labels (the component, and `slow` above about 5 s; `ctest -LE slow` runs the fast set) and timeouts, and a test source that is not registered fails the configure step. Continuous integration runs the thread sanitizer on propagation too and the Python suites once per pull request. The ruff version of the development extras matches pre-commit.
