Photon stream format 1.2: the optional `path` column (distance from emission to the row position, any frame) and the run key `ground_representation` (`plane`, default, or `sphere`). In sphere runs the ground-frame rows are 3D points on or inside the telescope sphere; consumers check them with `validate_sphere_rows`. `obdeect stream to-simtel` converts downward sphere rows on the sphere to sim_telarray plane rows and rejects rows emitted inside the sphere; `obdeect stream to-grisu` rejects sphere runs. Streams of format 1.0 and 1.1 are still read. The C API has the column `OBDEECT_STREAM_COLUMN_PATH` (ABI version 2).
