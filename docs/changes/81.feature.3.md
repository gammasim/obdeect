Ray tracing reads sphere runs (`ground_representation` `sphere`): each G row starts at its own point on or inside the telescope sphere, with its time there, and horizontal rows are traced from their sphere points. The sphere must enclose the optical model: `trace-stream` checks it per telescope (`telescope_r_m`) and names the element that is too far from the centre. Plane runs are unchanged. `trace_bunches` takes optional start heights `z` and paths. The photon column `path` is carried through `trace-stream` (output path = input path, moved to the start point, plus the traced path).
