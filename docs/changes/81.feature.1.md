Sphere representation of frame G in the atmosphere stage: `--ground-representation sphere` (Python `ground_representation`, run key `ground_representation = "sphere"`, format 1.2) writes the point where each photon's path enters the telescope sphere, with the columns `path` and `cz`. Rows are converted by straight lines, a hybrid rule that bends through the telescope plane, or a three-dimensional ray integrator near the horizon and for rays that turn over. The summary has the new drop reason `misses_sphere`. Extinction of sphere rows is not implemented yet and is rejected with an error (phase 5b-2).
