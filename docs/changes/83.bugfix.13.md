Reject invalid CORSIKA and photon-stream input instead of converting it silently: `to-simtel` refuses photons without a wavelength column (sim_telarray would sample a Cherenkov spectrum; a zero column is kept), a CORSIKA RUNH while a run is open is an error, empty input and truncated runs are reported, header numbers that are not finite integers are errors (they were undefined behaviour), a telescope index outside TELPOS and a particle block inside an array container are errors, trailing bytes after a CORSIKA payload are rejected, a read error of the input is no longer taken for the end of the stream, a fractional GrISU weight with `--expand-bunches` is an error, and a failed write (also at the final flush or close) exits with status 1 in every stream tool.
