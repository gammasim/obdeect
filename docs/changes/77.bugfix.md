`obdeect propagation run` accepts a fixed wavelength (`wavelength_min_nm` equal to
`wavelength_max_nm`, as written for monochromatic light sources), and in weighted mode any finite
bunch weight; the limit of 2048 photons per row applies to thinned mode only.

Source runs reject event counts outside the Philox key range and invalid row limits. Preset seed
overrides now affect preset randomness, malformed profile table rows are rejected, and the LED
preset imports with valid Python syntax.
