Sources accept photons in all directions. `to_plane_z0` moves photons that reach the plane z = 0 (from above or below) and drops and counts the others (`not_on_plane`, in the run summary and the `run_end` record) instead of failing. `plane_wave` accepts upward beams (`towards_source` with z < 0), and rejects horizontal ones. The `lidar`, `laser-beam` and `beam-scan` presets accept upward beams; `--max-tilt` counts from the vertical in the beam's own hemisphere.
