`obdeect ray-tracing trace-stream` traces several telescopes with their own optical models in one process: `--model ID=PATH`, repeated (Python: `trace_stream({id: model, ...}, ...)`). The output is one camera-frame stream in event order, so an array no longer needs one process per telescope and a merge of their streams. Each telescope block carries the efficiency status of its model. `--model PATH` (one model for every telescope) is unchanged.
