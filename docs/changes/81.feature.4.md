`obdeect stream from-corsika` converts CORSIKA 3D photon bunches (EventIO 1217). A run with 1217 blocks is written as a sphere run (`ground_representation` `sphere`, format 1.2): each bunch becomes its ground-frame row on or inside the telescope sphere, with `path`, `z` and `cz`. Bunches that miss the sphere are counted in the run end (`misses_sphere`). A run may not mix 1205 and 1217 blocks. CORSIKA runs now write `ground_representation` explicitly (`plane` for 1205 blocks).
