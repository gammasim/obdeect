# dlamb-beam-scan

Parallel downward beam scanned along two lines over the camera area, sky frame. Writer B,
producer `dlamb-beam-scan`.

## Options

| Option | Default | Meaning |
| --- | --- | --- |
| `-r rcam` | 123 | camera fiducial radius [cm]; finite and `> 0`, else `beam-scan: radius must be finite and positive` |
| `-x xpos` | `0.3 * 123 = 36.9` | scan start x [cm] |
| `-y ypos` | `0.2 * 123 = 24.6` | scan start y [cm] |
| `-h height` | `0.05 * 123 = 6.15` | source height [cm] |
| `--seed n` | 1 | |
| `-o fname` | stdout | |
| `--help` | | |

The defaults of x, y, height are derived from 123 cm and do not follow a later `-r`.

## Plan

Fixed: run number 1, observation level 2150 m, `atmosphere_id` 1, 100 photons per position,
bunch 1, wavelength 400 nm (`wavelength_min = wavelength_max = 400`), one telescope id 1 at
(0,0,0) with radius `r/100` m, 1 event, one case.

Scan positions in cm, generated by repeated addition in double precision (this fixes the
position count): first `x = xpos; x < xpos + 0.4 r; x += 0.001 r` at `y = ypos`, then `y = ypos;
y < ypos + 0.2 r; y += 0.001 r` at `x = xpos`. Each position `k = 0, 1, ...` (running over both
lines) is one emission: Emitter at `(x, y, height)/100` m, pointing `(0,0,-1)`, FixedAngle(0)
(parallel), Fixed 400 nm, Gaussian pulse with sigma 0 (all `t = 0`), `Source.photons = 100`,
bunch 1, seed `seed + k`, no target. Total rows `100 * positions` (default: more than 500 and
fewer than 700 positions), all `w = 1`, `cz = -1`, `z = 0.0615`.

`photons_per_position` and bunch size are fixed in the tool but exist as fields of
`XylsOptions` (see tests): photons `>= 0`, `<= 2^53` else `beam-scan: photons per position must
be finite, >= 0 and at most 2^53`; with `bunch 2`, `photons 6`: 3 rows per position of `w = 2`.
