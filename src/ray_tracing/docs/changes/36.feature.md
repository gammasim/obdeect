Added `obdeect trace-stream`: traces a gstrickd photon stream (G or T photons) through an optical model and writes camera-frame (C) photons, applying the mirror-reflectivity and telescope-transmission factors of the efficiency ledger (see photon-stream docs). With `--telescope-transmission angular`, only the angular part t(θ)/t0 is applied and the on-axis value is left as the pending ledger factor `telescope_transmission_constant`.
